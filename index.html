자주 묻는 질문 보기

빠른 도우미

업무 중 자주 하는 작은 정리 작업을 여기서 바로 처리하세요. 입력 내용은 서버로 보내지 않고 이 화면에서만 계산합니다. 결과를 누르면 복사됩니다.

스크립트 결과·메신저 내용처럼 섞인 글에서 차량번호만 골라 한 줄씩 정리합니다. 탁송체크 ‘차량목록 입력’에 그대로 붙여넣을 수 있어요.

② 정리된 차량번호
왼쪽에 붙여넣으면 바로 정리됩니다.
차량 0대

‘1억 2천만원’, ‘35,000원’, ‘천만원’처럼 적힌 금액을 숫자로 바꾸고 부가세(10%)·합계·한글 금액을 계산합니다.

탁송비용 부가세는 탁송체크와 같은 기준(비용의 10%)으로 계산합니다. 하나은행 이체파일은 1억 원 초과 금액을 건별 1억 원 이하로 자동 분할하며, 아래 ‘분할 건수’는 그 미리보기입니다.

‘국민 123-45-678901’처럼 적힌 글에서 은행 이름과 숫자만 남긴 계좌번호를 찾아 줍니다. 이체 내역 검토 때 원문과 대조하는 용도로 사용하세요.

② 은행 · 계좌번호
왼쪽에 붙여넣으면 바로 정리됩니다.
계좌 0건

예금주 확인이나 계좌 실재 여부는 확인하지 않습니다. 실제 계좌·수취인은 반드시 은행에서 확인하세요.

자주 묻는 질문

막히는 부분이 있으면 먼저 여기서 찾아보세요. 위 검색창에서도 찾을 수 있어요.

공통설치나 로그인이 필요한가요?

필요 없습니다. 브라우저에서 바로 동작하며 Mac·Windows 모두 사용할 수 있습니다. 직접 실행할 때는 저장소 폴더에서 python3 -m http.server 8000을 실행한 뒤 http://localhost:8000에 접속하세요.

공통입력한 내용이나 파일이 서버로 전송되나요?

아니요. 입력 내용과 첨부 파일은 모두 이 브라우저 안에서만 처리합니다. 다운로드한 파일은 사용자 기기에 남습니다.

탁송체크렌톡 결과가 이상하거나 비어 있어요

렌톡 시트는 조회 기준을 요청시각이 아닌 출발시각으로 바꾼 뒤 기간을 설정해 다운로드해야 합니다. 세 업체의 조회 기간이 같은지도 확인하세요.

탁송체크어떤 엑셀 파일을 첨부하나요?

한빛탁송·오픈마일·렌톡 각 업체에서 ‘탁송기한’ 조회 → 기간 설정 → 조회 → 시트 다운로드로 받은 파일 3개입니다. 첨부 후 파일명·인식된 업체·기록 건수가 맞는지 확인하세요.

탁송체크‘중복 검토 필요’는 무엇인가요?

같은 차량에 서로 다른 탁송 기록이 있을 때 표시됩니다. 상단 검토 목록 보기에서 날짜·업체·상태·금액을 비교해 표시할 탁송건을 한 건 선택하면 결과·복사·저장에 반영됩니다.

탁송체크색깔은 각각 무슨 뜻인가요?

주황은 확인 필요, 회색은 미조회, 파랑은 미완료(완료 대기)입니다. 한빛탁송의 빈 주유비는 0원, 오픈마일의 빈 금액은 미입력으로 처리합니다.

탁송체크수동확인이 눌리지 않아요

선택하지 않은 중복 탁송, 금액 충돌, 별도 운행 검토가 남아 있으면 수동확인을 할 수 없습니다. 탁송건을 하나 선택하거나 충돌을 해소한 뒤 다시 시도하세요.

이체파일Excel 다운로드 버튼이 안 눌려요

은행명·계좌번호·금액 같은 필수 항목에 오류가 남아 있으면 다운로드가 차단됩니다. 빨간 표시가 있는 칸을 원문과 대조해 고치세요. 인식하지 못한 은행은 드롭다운에서 직접 선택해야 합니다.

이체파일1억 원이 넘는 금액은 어떻게 되나요?

건별 1억 원 이하로 자동 분할합니다. 분할 후 총 100건까지 처리하며, 넘으면 기존 결과와 원문을 그대로 유지합니다. 위 금액 변환 도우미에서 분할 건수를 미리 볼 수 있어요.

이체파일차량번호가 없는 이체 요청은요?

‘차량번호 또는 원하는 이체 메모를 입력하세요’ 팝업이 열립니다. 차량번호로 입력하면 출금·입금통장표시 모두에, 이체 메모로 입력하면 입금통장표시에만 적용됩니다. 빈칸으로 진행하거나 취소할 수도 있습니다.

이체파일실수로 지웠어요. 되돌릴 수 있나요?

페이지를 열어 둔 동안 되돌리기와 마지막 다운로드 내역 복원을 사용할 수 있습니다. 같은 탭에서 단계를 오가거나 새로고침해도 마지막 저장 후 4시간 이내 내용은 복원됩니다.

이체파일어떤 금액 표현을 인식하나요?

35,000원, 1000만원, 천만원, 1억 2천만원 등을 인식합니다. 음수·소수·잘못된 쉼표 표기는 자동 보정하지 않고 검토 대상으로 남깁니다.

해당하는 질문이 없습니다. 탁송체크 또는 이체파일 상세 사용방법을 확인해 보세요.
