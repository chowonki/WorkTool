# Change Log

WorkTool의 사용자에게 영향을 주는 주요 변경사항이에요. 날짜는 `main` 반영 이력의 한국 시간(Asia/Seoul) 기준이며, 같은 날의 수정은 최종 반영된 동작으로 요약했어요.

[웹에서 보기](./changelog.html) · [사용방법 및 프로젝트 소개](./README.md) · [전체 커밋 이력](https://github.com/chowonki/WorkTool/commits/main/)

## 2026-11-27 · Windows·Mac 앱 새 디자인 · Mac 앱 · v0.3.0

- Windows 앱: Windows 11 Fluent 모양으로 새로 꾸몄어요. Mica 배경, 왼쪽 탐색 창, 위쪽 명령 막대, 표, 오른쪽 입력·정보 패널로 나눴어요. 탁송체크의 보기(전체·확인 필요·금액 확인·진행 중·미조회·제주 출발·캐리어탁송·슬랙봇 문의·슬랙 회신 반영)와 이체파일 1·2·3단계는 탐색 창 하위 항목으로 옮기고 대수·건수를 함께 보여 줘요. 숫자 카드와 단계 표시줄은 없앴어요.
- Windows 앱: 메뉴·제목에 색 아이콘을 넣고, 조회 상태·이체 상태를 색 알약으로 보여 줘요. 라이트·다크 모두 맞춰요. 글꼴은 Segoe UI Variable(한글 맑은 고딕)이에요.
- Windows 앱: 이체파일 2단계를 편집 가능한 표로 바꾸고, 선택한 건의 원문·확인 사항·통장 메모 일괄 입력을 오른쪽 패널에 모았어요.
- Windows·Mac 앱: 차량목록에 붙여넣으면 빈 줄을 알아서 지워요. 조회할 때도 한 번 더 정리해요. 한 글자씩 칠 때는 그대로라 줄 추가가 돼요.
- Mac 앱(새로 추가): 탁송체크와 하나은행 이체파일을 쓰는 SwiftUI 앱이에요. 웹과 같은 규칙을 macOS 내장 JavaScriptCore로 실행하고, macOS 27 Golden Gate 모양(전체 높이 사이드바·도구 막대·오른쪽 패널)과 색 아이콘을 따라요. Apple Silicon·Intel, macOS 14 이상.

## 2026-11-26 · 조회 결과 페이지 나누기 · 탁송일정 양식 통일

- 탁송체크: 탁송일정을 3사 모두 **YYYY-MM-DD HH:MM** 모양으로 맞춰요. 시간이 없는 건은 00:00을 붙여요. 표·복사·TXT/엑셀/PDF·캡처 모두 같은 모양이에요.
- 탁송체크: 탁송일정이 중첩이면 탁송비용 칸에 비용 선택창을 띄우지 않아요. '일정 선택 후 표시'로 기다렸다가, 일정을 고르면 그 기록의 비용이 채워져요. 일정은 하나인데 비용만 다를 때만 비용을 따로 골라요(웹·Windows 앱).
- 탁송체크: 중첩된 일정·비용을 고르면 조회 상태·탁송 상태·업체명·주유비·비용 구분·출발지·원본 위치도 고른 기록으로 바뀌어요(웹·Windows 앱). 렌톡 기록을 고르면 슬랙봇 문의·제주 출발도 렌톡 기준으로 바뀌고, 이미 받은 슬랙봇 회신 금액은 유지해요.
- 탁송체크: 중첩된 일정·비용을 고르면 표 칸이 고른 값으로 바뀌어요. 다른 칸처럼 눌러서 복사되고, 고른 기록의 업체·파일은 마우스를 올리면 보여요. ↺ 단추로 다시 고를 수 있어요.
- 탁송체크: 렌톡 탁송일정 칸에 보이지 않는 문자·따옴표·시간대(+09:00)·뒤 글자가 섞여 초까지(`HH:MM:ss`) 그대로 보이던 문제를 고쳐, 안에 든 날짜·시간을 찾아 같은 모양으로 맞춰요. `예약 요청`처럼 날짜가 없는 글자는 그대로 보여요.
- Windows 앱 탁송체크: 웹과 같이 결과를 **한 페이지에 30건씩**(10·30·50·100건 선택, 이 기기에 기억) 보여 주고, 페이지 번호 단추로 넘길 수 있어요. 탁송일정도 3사 모두 같은 모양으로 보여요.
- 탁송체크: 조회 결과를 **한 페이지에 30건씩** 보여 줘요. 표 아래 페이지 번호·‹ › 단추로 넘기고, **페이지당** 드롭다운에서 10·30·50·100건을 고를 수 있어요(이 기기에 기억). 중첩 일정·비용 드롭다운도 표에 맞게 작게 줄였어요. 필터·검색·정렬을 바꾸면 1페이지로 돌아가요. 복사·저장·캡처와 전체 선택은 다른 페이지 결과도 함께 포함해요.

## 2026-11-25 · 실수 방지 보강 · Windows 포터블

- 탁송체크: 업체 엑셀의 탁송일정·탁송비용·렌톡 캐리어 구분 열 값이 절반 넘게 평소 형식과 다르면 **업체 양식이 바뀌었을 수 있다고** 알려 줘요. 파일 목록에도 '⚠ 양식 확인 필요'가 붙어요.
- 탁송체크: '복사함·완료' 표시를 오늘 하루 동안 이 기기에 남겨요. 실수로 새로고침하거나 다시 조회해도 이어서 볼 수 있어요. 전체 초기화를 누르면 지워져요.
- 이체파일: 오늘 이미 받은 이체파일과 은행·계좌·금액이 같은 건이 있으면 다운로드 전에 한 번 더 물어봐요. 계좌번호 원문은 남기지 않아요.
- 슬랙봇 회신 금액을 10원 단위로 반올림해요.
- Windows 앱: 같은 기능을 넣고, 압축만 풀면 바로 실행되는 포터블 ZIP(WorkTool.exe)을 만들었어요. 설정·표시는 ZIP 옆 Data 폴더에 남아요.

## 2026-11-18 · 그림 사용법 체험 화면 · 사용 설명서 정리 · 다크 모드

- 그림 사용법에 직접 눌러 보는 체험 화면을 넣었어요. 탁송체크는 차량목록 붙여넣기 → 파일 첨부 → 조회 → 걸러 보기·일정 고르기·복사까지, 이체파일은 붙여넣기 → 추출 → 오류 고치기·통장 메모 → 검토 확인 → 다운로드·송금 코멘트까지 실제처럼 따라 해 볼 수 있어요. 위쪽 ‘지금 할 일’이 다음에 누를 곳을 알려 줘요.
- 체험 화면은 가상 데이터만 쓰고 파일을 만들거나 저장하지 않아요. 실제 화면 스크린샷은 체험 화면 아래 링크로 볼 수 있어요.
- 다크 모드에서 사용법 페이지(그림 사용법·탁송체크·이체 상세 사용방법) 글자가 흰 바탕에 묻혀 안 보이던 문제를 고쳤어요. 라이트 모드의 그림 사용법 위쪽 메뉴 글자도 진하게 했어요.
- 쓰지 않던 사용 설명서(guide.html)를 지웠어요. 예전 주소로 들어오면 그림 사용법으로 옮겨 가요. 홈 메뉴의 '사용 설명서'도 '그림 사용법'으로 바꿨어요.

## 2026-11-18 · 가독성 개선

- 탁송체크 글자를 읽기 쉽게 다듬었어요. 탭·필터·카드 이름·표 머리글·파일 정보처럼 10~12px이던 보조 글자를 13px 안팎으로 키웠어요.
- 흐리던 회색 글자와 상태 배지(비용 확인·슬랙봇 문의·미조회 등)를 진하게 해서, 라이트·다크 모드 모두 웹 접근성 대비 기준(4.5:1)을 넘게 했어요.
- 첨부 파일 목록이 3개까지 한눈에 보이고, '주유비용/충전비용 (원)'·'부가세 10%' 머리글이 잘리지 않게 열 너비를 넓혔어요.

## 2026-11-18 · 미조회 대신 진행 중 표시

- 탁송체크 위쪽 카드와 탭의 '미조회'를 '진행 중'으로 바꿨어요. 진행 중은 기록은 있지만 아직 탁송완료 전인, 탁송 중·배정완료 차량이에요(취소는 제외). 표·캡처·저장 파일의 상태도 '진행 중'으로 보여요. 미조회 차량은 '확인 필요' 탭에서 볼 수 있어요.

## 2026-11-18 · 표 글자 굵기 정리 · 눌러서 복사 안내

- 탁송체크 표의 '금액 (원)' 항목 이름을 '주유비용/충전비용 (원)'으로 바꿨어요. 캡처 이미지, TXT·엑셀·PDF 저장 파일, 사용법 문서의 이름도 같이 바꿨어요.
- 탁송체크 표에서 과하게 굵던 글자를 정리했어요. 값은 보통 굵기로, 차량번호와 주유금액만 살짝 강조해요.
- 눌러서 복사되는 값에 점선 밑줄과 '복사' 표시를 붙이고, 표 위에 안내 문구를 넣었어요. 차량번호·주유금액에 더해 탁송일정·탁송비용·부가세도 눌러서 복사할 수 있어요. 숫자는 쉼표 없이 복사돼요.
- 주유금액을 쉼표가 있는 숫자(12,350)로 보여 줘요.
- 다크 모드에서 한 줄 걸러 밝은 회색 배경이 나와 글자가 잘 안 보이던 문제를 고쳤어요.

## 2026-11-18 · 결과 캡처 추가 · 체험·예시 데이터 제거

- 탁송체크에 **결과 캡처**를 넣었어요. 결과 내보내기 줄의 **캡처 복사**는 조회 결과를 표 이미지로 클립보드에 복사하고(Slack에 바로 붙여넣기), **캡처 저장**은 PNG 파일로 저장해요. 저장 범위와 체크한 줄을 따르고, 합계가 함께 들어가요.
- 쓰지 않는 탁송체크 '체험 데이터'와 이체파일 '예시로 연습하기'를 지웠어요.
- 한글이 숫자 문자 참조(&#52264; 같은 형식)로 저장된 엑셀도 탁송체크가 읽을 수 있게 했어요.
- 사용법 그림은 가상 업체 엑셀·가상 이체 요청으로 다시 찍었어요.

## 2026-11-18 · 불필요한 항목 정리

- 이체파일 1단계 오른쪽 '입력 예시' 상자를 지웠어요. '예시로 연습하기' 버튼은 입력칸 아래 버튼 줄로 옮겼고, 누르면 예시가 입력칸에 바로 들어가요. 입력칸이 화면 너비를 다 쓰고, 휴대폰에서는 1단계가 한 화면에 들어와요.
- 탁송체크: 제목 위아래의 영문 표시·설명 문장, '이 기기에서만 처리' 표시, 카드 안 안내 문장, '자동인식' 표시, 조회 버튼 아래 안내, 빈 화면 태그, 아래쪽 열 안내 줄을 지웠어요.
- 탁송체크 표: '선택'과 '완료' 체크를 나란히 놓아 한 줄 높이를 줄이고, 전체 선택·필터 지우기·열 너비 초기화를 '조회 결과' 제목 줄로 올렸어요.
- 이체파일: 단계 버튼의 보조 설명, 1단계 도움말 상자(사용 안내 창과 중복), 2단계의 반복 안내, 3단계 열 순서 설명을 지우고 남은 안내 문장은 짧게 줄였어요.
- 홈: 긴 설명 문장을 줄이고 아래쪽 버전 표시를 지웠어요.
- 바뀐 화면에 맞춰 사용법 그림을 다시 만들었어요.

## 2026-11-18 · 화면 배치 정리

## 2026-11-17 · 이체파일 오류 방지 보완

- 이미 추출한 스레드를 고쳐서 다시 추출하면 **전에 넣은 건은 다시 넣지 않고 새 건만 추가**해요. 같은 스레드를 다른 입력칸에 또 붙여넣으면 건너뛰어요.
- 같은 은행·계좌·금액이 두 줄 이상이면 **'두 번 송금 주의'** 검토로 표시해요. 휴대폰 번호 형태의 계좌번호도 원문 확인 검토로 표시해요.
- 날짜·시간 줄(예: 2026-11-17 14:30)을 계좌번호로 잘못 읽지 않아요.
- 나누면 100건을 넘는 큰 금액은 화면이 멈추지 않도록 나누지 않고 오류로 표시해요.
- 메모에 섞인 보이지 않는 제어문자를 지워 **엑셀 파일이 깨지지 않게** 했어요.
- 검토 확인 체크 후 내역을 바꾸면 체크가 풀려 다시 확인해야 받을 수 있어요. 다운로드 버튼을 연달아 눌러도 파일이 한 번만 저장돼요.
- 붙여넣기 글자 수 한도를 5만 자로 늘리고, 넘쳐서 잘리면 안내해요. 받지 않은 내역이 있을 때 새로고침·창 닫기를 하면 한 번 물어요.
