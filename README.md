# WorkTool

탁송 차량 조회와 하나은행 다계좌이체 파일 생성을 위한 브라우저 기반 업무 도구예요. 로그인 없이 사용하며, 입력 내용과 첨부 파일은 브라우저에서 처리해요.

처음 사용하는 분은 [그림으로 보는 빠른 사용법](./quick-guide.html)에서 **실제 WorkTool 화면에 번호·화살표·부가설명을 표시한 안내 이미지 4장**을 확인할 수 있어요. 입력 화면은 가상 예시 데이터로 촬영했으며 사내 시스템 화면은 포함하지 않아요.

## 변경 이력

[Change Log 페이지](./changelog.html) · [CHANGELOG.md](./CHANGELOG.md)에서 날짜별 주요 변경사항을 확인할 수 있어요. 홈과 두 도구 상단에서도 새 탭으로 열 수 있어요.

## 화면 구성

탁송체크와 하나은행 이체파일은 같은 Liquid Glass 스타일(반투명 유리 판, 파란 강조색)을 써요. 위쪽 메뉴에서 **화면**을 자동·라이트·다크 중에 고를 수 있어요. 탁송체크는 **위쪽 차량목록·업체 파일 / 아래쪽 조회 결과**로 나뉘고, 하나은행 이체파일은 한 화면에서 **① 이체 요청 입력 → ② 추출 결과 확인·수정 → ③ 이체파일 다운로드** 세 단계로 진행해요. 휴대폰에서는 세로 배치로 바뀌어요.

## 주요 기능

| 도구 | 설명 |
| --- | --- |
| **탁송체크** | 차량목록과 업체 엑셀을 대조해 탁송 상태, 주유금액, 확인이 필요한 차량을 정리해요. |
| **하나은행 이체파일** | Slack 스레드에서 이체 정보를 추출하고 검토한 내용을 은행 업로드용 Excel 파일로 만들어요. |

## 시작하기

별도의 패키지 설치나 빌드 없이 정적 웹 서버로 실행할 수 있어요.

```bash
git clone https://github.com/chowonki/WorkTool.git
cd WorkTool
python3 -m http.server 8000 --bind 127.0.0.1
```

Python 3가 설치된 환경에서 실행한 뒤 [http://localhost:8000](http://localhost:8000)에 접속해요. 종료할 때는 터미널에서 `Ctrl+C`를 눌러요.

탁송체크는 같은 출처의 iframe에 있는 화면을 확장하므로 로컬 HTTP 서버로 여는 방식을 권장해요. 정적 호스팅을 이용할 때도 아래 HTML 파일들을 같은 폴더에 배치해요.

## 탁송체크 사용 방법

**체험 데이터**에도 업체별 접수 시각 열과 완료일시를 포함해요. `12서7567`·`25마7579`는 중복 검토·최신순 선택, `77다1234`는 캐리어 분류를 확인하는 예시예요.

[탁송체크 상세 사용방법](./dispatch-guide.html)에서 입력 예시, 업체별 금액 처리, 상태 색상, 수동확인, 필터와 저장 범위를 확인할 수 있어요. 홈과 탁송체크 상단의 **상세 사용방법** 링크는 작업을 유지하도록 새 탭으로 열려요.

1. 사내 **‘탁송출발 주유비 미입력’ 스크립트**를 실행한 뒤, 결과에서 필요한 **차량번호를 추출·복사**해요.
2. WorkTool의 **차량목록 입력**에 복사한 차량번호를 붙여넣어요. 날짜·시간이 함께 복사된 목록도 사용할 수 있어요.
3. **한빛탁송·오픈마일·렌톡** 각 업체에서 **‘탁송기한’ 조회 → 기간 설정 → 조회 → 시트 다운로드**를 진행해요. **렌톡은 요청시각이 아닌 출발시각 기준**으로 조회해요.
4. 다운로드한 **3사 엑셀 시트**를 **업체 파일 첨부**에 넣고 파일명·인식된 업체·기록 건수를 확인해요.
5. **차량 조회하기**를 누른 후 미조회·미완료·주유비 확인 필요·중복 차량을 점검하고 필요한 결과를 복사하거나 TXT·Excel·PDF로 저장해요.

### 조회 및 검토 기준

- 탁송비용은 한빛탁송 AP열·오픈마일 U열·렌톡 S열에서 읽고, 탁송비용 부가세는 해당 비용의 10%로 계산해요. 총 탁송비용은 비용과 부가세의 합계예요. 세 항목을 각각 클릭해 숫자만 복사할 수 있고 표와 TXT·Excel·PDF에 세 항목을 표시하며, 빈칸은 미입력으로 둬요. 중복 건 선택 시 해당 기록의 비용을 적용해요.

- 접수일시는 한빛탁송 I열, 오픈마일 A열, 렌톡 C열 요청 시각을 우선 읽어 최신 기록 비교와 선택 목록에 반영해요.
- 중복 기록에 탁송완료일시·탁송접수일시를 표시하고 둘 중 최신 시각으로 정렬해요. 시각 정보가 없으면 탁송일시를 사용하며, 입력 날짜가 있으면 같은 운행일 내에서 비교해요. 금액 충돌·별도 운행은 사용자가 최종 선택해요.

- 원본에 탁송 시간이 있으면 결과·기록 선택·조회 근거·TXT·Excel·PDF에 탁송일시를 표시해요. 날짜만 있는 원본은 날짜만 표시해요. 날짜 매칭과 기간 필터는 일자 기준이며, 시간이 다른 기록은 별도 건으로 구분해요.

- 차량목록에 날짜가 있으면 같은 운행일의 기록을 조회하고, 날짜가 없으면 해당 차량의 업체 전체 기록에서 완료·접수일시 중 최신 시각을 기준으로 조회하고, 해당 시각이 없으면 탁송일시를 사용해요.
- 상단 **중복 검토 필요 N대 → 검토 목록 보기**와 **중복 검토 필요** 탭에서 표시할 탁송건을 아직 선택하지 않은 다중 기록 차량만 모아 볼 수 있어요. 링크는 기존 필터를 해제하고 전체 검토 대상을 표시하며, 한 건을 선택하면 해당 차량을 검토 목록에서 제외해요.
- 원본 기록과 이전 기록을 조회 근거에서 확인할 수 있어요. 동일 차량에 서로 다른 탁송 기록이 있으면 **표시할 탁송건 선택**에서 날짜·업체·상태·금액을 비교해 한 건을 적용할 수 있어요. 선택한 기록이 결과·복사·저장에 반영되며, 자동 조회로 되돌릴 수 있어요. 선택은 현재 페이지에서만 유지되고 원본 변경 시 다시 선택해요.
- 한빛탁송의 주유/부대비용 총액이 빈칸이면 `0원`으로 처리해요. 오픈마일의 빈 금액은 미입력으로 유지하며, 숫자 `0`은 주유비 없음으로 구분해요.
- 확인 필요는 주황색, 미조회는 회색, 미완료(완료 대기)는 파란색으로 구분해요.
- 같은 기준일에 완료 금액이 서로 다르거나 별도 운행 여부가 불명확하면 검토 대상으로 표시해요.
- 같은 차량의 서로 다른 날짜 기록을 각각 출력하려면 날짜별로 나눠 조회해요. 한 건만 표시하려면 탁송건 선택 기능을 사용해요.
- 렌톡 시트 J열 **캐리어탁송**이 `Y`인 조회 기준일의 기록만 캐리어로 분류하고 렌톡 문의 목록에서 제외해요. 다른 운행일의 캐리어 표시를 현재 조회에 전파하지 않아요. 메모·비고 문구는 캐리어 판정 기준으로 사용하지 않아요.
- 선택되지 않은 중복 탁송·금액 충돌·별도 운행 검토·탁송비용 충돌이 있는 상태에서는 수동확인을 적용하지 않아요. 하나의 탁송건을 선택하거나 충돌을 해소한 후에만 수동확인이 가능해요. 완료 건의 확인 금액과 사유를 저장할 수 있어요. 원본 기록이 바뀌면 다시 확인해야 해요.
- 차량번호 단위로 선택해 복사·저장하거나 처리 완료 표시를 할 수 있어요. 체크박스를 누른 채 행 위로 드래그하면 연속 선택·해제하며, 업체별 체크박스로 현재 표시 조건의 해당 업체 차량을 일괄 선택·해제할 수 있어요.

## 하나은행 이체파일 사용 방법

[이체파일 상세 사용방법](./transfer-guide.html)에서 입력 예시, 금액 읽는 기준, 확인·수정, 통장 메모, 다운로드와 송금 코멘트를 자세히 볼 수 있어요.

1. 홈에서 **하나은행 이체파일**을 열어요.
2. Slack 스레드를 입력칸에 붙여넣어요. 스레드가 여러 개면 **+ 입력칸 추가**로 나눠 넣어요.
3. **이체정보 추출하기**(또는 `Ctrl+Enter` / Mac `⌘+Enter`)를 누르면 2단계로 넘어가요.
4. 은행·계좌번호·금액·차량번호를 원문과 대조하고, 빨간 칸(오류)을 고쳐요. 필요하면 통장 메모와 CMS코드를 넣어요.
5. 3단계에서 미리보기를 확인하고 **하나은행 이체파일 다운로드**를 눌러요.

### 추출 및 다운로드 기준

- 이미 추출한 스레드는 두 번 들어가지 않아요. 같은 스레드를 다른 칸에 또 붙여넣으면 건너뛰고, 추출한 스레드에 내용을 덧붙여 다시 추출하면 새로 붙인 건만 추가해요.
- `35,000원`, `3만5천원`, `1000만원`, `천만원`, `1억 2천만원` 같은 금액을 읽어요. `3.5억`, `35,000.50원`, `-35,000원`, `1/2만원`, `35,00원`처럼 잘못 읽으면 엉뚱한 금액이 되는 표기나, 한 줄에 금액이 여러 개인 경우는 비워 두고 직접 확인하게 해요.
- 날짜·시간 줄(`2026-11-17 14:30`)은 계좌번호로 보지 않아요.
- 1억 원을 넘는 금액은 1억 원씩 + 나머지로 나눠요. 나눈 줄을 포함해 한 파일에 100건까지예요. 나누면 100건을 넘는 큰 금액은 나누지 않고 오류로 표시해요.
- 차량번호를 못 찾으면 팝업에서 차량번호나 입금통장 이체 메모를 넣을 수 있어요. 비워 두면 '검토'로 남아요.
- **오류**(은행 미선택, 계좌번호 형식, 금액 없음·0원·숫자 아님, 1억 초과 미분할)가 남으면 다운로드할 수 없어요.
- **검토**(차량번호·메모 없음, 같은 계좌 중복, 같은 계좌·같은 금액 중복 '두 번 송금 주의', 휴대폰 번호 모양 계좌, 1억 이상)는 3단계에서 확인 체크를 해야 받을 수 있어요. 체크한 뒤 내역을 바꾸면 체크가 풀려요.
- 은행은 하나은행 입금은행코드표·증권사코드표 기준 드롭다운에서 골라요. `KB국민`, `NH농협`, `카뱅` 같은 약칭도 알아봐요.
- 파일 이름: `하나은행_다계좌이체_YYYYMMDD_HHMM_차량번호_금액.xlsx`. 차량 3대까지는 차량별 금액, 4대 이상은 `첫번호외N대_총금액`으로 적어요.
- 받은 뒤에도 내역은 화면에 남아 있어요. 파일 저장을 확인한 뒤 **전체 초기화**를 눌러 주세요.
- 3단계의 **송금 코멘트**는 같은 차량번호를 한 줄로 묶어요. 차량대금·차대금·환급 문구가 있으면 '딜러에게', 은행 줄 위에 `(압류 계좌)` 같은 괄호 줄이 있으면 그 문구로, 아니면 은행·계좌번호로 적어요.

## 데이터 보관

- 입력 내용과 첨부 파일은 서버로 보내지 않고 브라우저 안에서만 처리해요.
- 하나은행 이체파일은 입력 내용을 저장하지 않아요. 새로고침하거나 창을 닫으면 지워져요. 아직 받지 않은 내역이 있으면 닫기 전에 한 번 물어봐요.
- 화면 모드(자동·라이트·다크)와 표 열 너비만 이 기기에 기억해요.
- 받은 파일은 사용자 기기에 남아요.

## 파일 구성

```text
WorkTool/
├── index.html            # 업무 도구 홈
├── dispatch.html         # 탁송체크
├── transfer.html         # 하나은행 이체파일 (추출·확인·Excel 생성)
├── guide.html            # 처음 쓰는 분을 위한 사용 설명서
├── quick-guide.html      # 그림으로 보는 빠른 사용법
├── dispatch-guide.html   # 탁송체크 상세 사용방법
├── transfer-guide.html   # 이체파일 상세 사용방법
├── changelog.html        # 웹 변경 이력
├── transfer-input/review/download.html  # 예전 주소 → transfer.html로 이동
├── dispatch-tool.html    # 예전 탁송체크 화면 (지금은 연결된 곳이 없음)
├── assets/mac-glass.css  # 공통 Liquid Glass 스타일
├── assets/theme.js       # 화면 모드(자동·라이트·다크)
├── guide/                # 사용법 스크린샷
├── tests/                # 자동 테스트
└── scripts/e2e-transfer.cjs  # 이체파일 브라우저 테스트
```

HTML·CSS·JavaScript로만 된 정적 웹 프로젝트예요. 빌드 과정이 없어요.

## 회귀 테스트

Node.js 18 이상에서 따로 설치할 것 없이 실행해요.

```bash
node --test tests/*.test.cjs
```

- `tests/transfer.test.cjs`: 금액·은행·계좌·날짜 줄 읽기, 엑셀 XML·ZIP 작성, 안전장치
- `tests/dispatch.test.cjs`: 차량목록 읽기, 업체 양식 인식, 조회 상태, 캐리어·제주, 탁송비용·부가세, TXT 저장
- `tests/shared-ui.test.cjs`, `tests/visual-guide.test.cjs`: 공통 스타일·메뉴·링크·사용법 이미지

이체파일은 실제 Chrome으로도 확인해요.

```bash
python3 -m http.server 8765 --bind 127.0.0.1 &
npm install --no-save playwright-core
CHROME_BIN=$(command -v google-chrome) node scripts/e2e-transfer.cjs
```

## 안전 점검

- 이체파일을 만드는 건 송금 실행이나 완료 확인이 아니에요. 은행 업로드 화면에서 받는 분·금액을 꼭 확인해 주세요.
- 엑셀에 들어가는 글자에서 파일을 깨뜨리는 제어문자를 지우고, `&`, `<` 같은 특수문자는 안전하게 바꿔 적어요.
- 다운로드 버튼을 연달아 눌러도 파일은 한 번만 저장돼요.
