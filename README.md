# WorkTool

탁송 차량 조회와 하나은행 다계좌이체 파일 생성을 위한 브라우저 기반 업무 도구입니다. 로그인 없이 사용하며, 입력 내용과 첨부 파일은 브라우저에서 처리합니다.

## 변경 이력

[Change Log 페이지](./changelog.html) · [CHANGELOG.md](./CHANGELOG.md)에서 날짜별 주요 변경사항을 확인할 수 있습니다. 홈과 두 도구 상단에서도 새 탭으로 열 수 있습니다.

## 주요 기능

| 도구 | 설명 |
| --- | --- |
| **탁송체크** | 차량목록과 업체 엑셀을 대조해 탁송 상태, 주유금액, 확인이 필요한 차량을 정리합니다. |
| **하나은행 이체파일** | Slack 스레드에서 이체 정보를 추출하고 검토한 내용을 은행 업로드용 Excel 파일로 만듭니다. |

## 시작하기

별도의 패키지 설치나 빌드 없이 정적 웹 서버로 실행할 수 있습니다.

```bash
git clone https://github.com/chowonki/WorkTool.git
cd WorkTool
python3 -m http.server 8000 --bind 127.0.0.1
```

Python 3가 설치된 환경에서 실행한 뒤 [http://localhost:8000](http://localhost:8000)에 접속합니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

탁송체크는 같은 출처의 iframe에 있는 화면을 확장하므로 로컬 HTTP 서버로 여는 방식을 권장합니다. 정적 호스팅을 이용할 때도 아래 HTML 파일들을 같은 폴더에 배치합니다.

## 탁송체크 사용 방법

**체험 데이터**에도 업체별 접수 시각 열과 완료일시를 포함합니다. `12서7567`·`25마7579`는 중복 검토·최신순 선택, `77다1234`는 캐리어 분류를 확인하는 예시입니다.

[탁송체크 상세 사용방법](./dispatch-guide.html)에서 입력 예시, 업체별 금액 처리, 상태 색상, 수동확인, 필터와 저장 범위를 확인할 수 있습니다. 홈과 탁송체크 상단의 **상세 사용방법** 링크는 작업을 유지하도록 새 탭으로 열립니다.

1. 홈에서 **탁송체크**를 선택합니다.
2. 한빛탁송·오픈마일·렌톡 업체 엑셀 파일을 첨부합니다.
3. 조회할 차량목록을 입력하고 조회를 실행합니다.
4. 상태, 업체, 날짜, 캐리어 여부, 주유비 확인 상태 등으로 결과를 좁혀 확인합니다.
5. 필요한 차량번호와 금액을 복사하거나 결과를 TXT·Excel·PDF로 저장합니다.

### 조회 및 검토 기준

- 탁송비용은 한빛탁송 AP열·오픈마일 U열·렌톡 S열에서 읽고, 탁송비용 부가세는 해당 비용의 10%로 계산합니다. 총 탁송비용은 비용과 부가세의 합계입니다. 세 항목을 각각 클릭해 숫자만 복사할 수 있고 표와 TXT·Excel·PDF에 세 항목을 표시하며, 빈칸은 미입력으로 둡니다. 중복 건 선택 시 해당 기록의 비용을 적용합니다.

- 접수일시는 한빛탁송 I열, 오픈마일 A열, 렌톡 C열 요청 시각을 우선 읽어 최신 기록 비교와 선택 목록에 반영합니다.
- 중복 기록에 탁송완료일시·탁송접수일시를 표시하고 둘 중 최신 시각으로 정렬합니다. 시각 정보가 없으면 탁송일시를 사용하며, 입력 날짜가 있으면 같은 운행일 내에서 비교합니다. 금액 충돌·별도 운행은 사용자가 최종 선택합니다.

- 원본에 탁송 시간이 있으면 결과·기록 선택·조회 근거·TXT·Excel·PDF에 탁송일시를 표시합니다. 날짜만 있는 원본은 날짜만 표시합니다. 날짜 매칭과 기간 필터는 일자 기준이며, 시간이 다른 기록은 별도 건으로 구분합니다.

- 차량목록에 날짜가 있으면 같은 운행일의 기록을 조회하고, 날짜가 없으면 해당 차량의 업체 전체 기록에서 완료·접수일시 중 최신 시각을 기준으로 조회하고, 해당 시각이 없으면 탁송일시를 사용합니다.
- 상단 **중복 검토 필요 N대 → 검토 목록 보기**와 **중복 검토 필요** 탭에서 표시할 탁송건을 아직 선택하지 않은 다중 기록 차량만 모아 볼 수 있습니다. 링크는 기존 필터를 해제하고 전체 검토 대상을 표시하며, 한 건을 선택하면 해당 차량을 검토 목록에서 제외합니다.
- 원본 기록과 이전 기록을 조회 근거에서 확인할 수 있습니다. 동일 차량에 서로 다른 탁송 기록이 있으면 **표시할 탁송건 선택**에서 날짜·업체·상태·금액을 비교해 한 건을 적용할 수 있습니다. 선택한 기록이 결과·복사·저장에 반영되며, 자동 조회로 되돌릴 수 있습니다. 선택은 현재 페이지에서만 유지되고 원본 변경 시 다시 선택합니다.
- 한빛탁송의 주유/부대비용 총액이 빈칸이면 `0원`으로 처리합니다. 오픈마일의 빈 금액은 미입력으로 유지하며, 숫자 `0`은 주유비 없음으로 구분합니다.
- 확인 필요는 주황색, 미조회는 회색, 미완료(완료 대기)는 파란색으로 구분합니다.
- 같은 기준일에 완료 금액이 서로 다르거나 별도 운행 여부가 불명확하면 검토 대상으로 표시합니다.
- 같은 차량의 서로 다른 날짜 기록을 각각 출력하려면 날짜별로 나눠 조회합니다. 한 건만 표시하려면 탁송건 선택 기능을 사용합니다.
- 렌톡 시트 J열 **캐리어탁송**이 `Y`인 조회 기준일의 기록만 캐리어로 분류하고 렌톡 문의 목록에서 제외합니다. 다른 운행일의 캐리어 표시를 현재 조회에 전파하지 않습니다. 메모·비고 문구는 캐리어 판정 기준으로 사용하지 않습니다.
- 선택되지 않은 중복 탁송·금액 충돌·별도 운행 검토·탁송비용 충돌이 있는 상태에서는 수동확인을 적용하지 않습니다. 하나의 탁송건을 선택하거나 충돌을 해소한 후에만 수동확인이 가능합니다. 완료 건의 확인 금액과 사유를 저장할 수 있습니다. 원본 기록이 바뀌면 다시 확인해야 합니다.
- 차량번호 단위로 선택해 복사·저장하거나 처리 완료 표시를 할 수 있습니다. 체크박스를 누른 채 행 위로 드래그하면 연속 선택·해제하며, 업체별 체크박스로 현재 표시 조건의 해당 업체 차량을 일괄 선택·해제할 수 있습니다.

## 하나은행 이체파일 사용 방법

[하나은행 이체툴 상세 사용방법](./transfer-guide.html)에서 입력 예시, 차량 선택, 금액 분할·검증, 통장 메모, 다운로드와 복원 방법을 확인할 수 있습니다. 홈과 이체툴의 **상세 사용방법** 링크는 새 탭으로 열립니다.

1. 홈에서 **하나은행 이체파일**을 선택합니다.
2. Slack 스레드 내용을 입력칸에 붙여넣습니다. 여러 입력칸을 추가하거나, 한 입력칸에서 스레드 사이에 `---`를 한 줄 넣어 구분할 수 있습니다.
3. **새 스레드 추가 추출**을 누릅니다. `Ctrl+Enter` 또는 Mac의 `⌘+Enter`로도 추출할 수 있습니다.
4. 은행명·계좌번호·금액·차량번호를 원문과 대조하고, 필요한 항목을 수정합니다.
5. 필요하면 선택한 행을 삭제하거나 출금·입금통장 메모와 CMS코드를 입력합니다.
6. **하나은행 양식 Excel 다운로드**를 누릅니다.

### 추출 및 다운로드 기준

- 기존 추출 결과에 새 이체 건을 누적합니다. 정상 추가된 입력 내용은 비우고, 추출하지 못한 스레드는 입력칸에 남깁니다.
- `35,000원`, `1000만원`, `천만원`, `1억 2천만원` 등의 금액 표현을 인식합니다. 금액이 여러 개이거나 의미가 불명확하면 직접 검토해야 합니다.
- 1억 원 초과 금액은 건별 1억 원 이하로 자동 분할합니다. 분할 후 총 100건까지 처리하며, 한도 초과 시 기존 결과와 입력 원문을 유지합니다.
- 차량번호는 선택 항목이며 출금·입금통장표시의 기본값으로 사용합니다.
- 음수·소수·잘못된 쉼표 표기의 금액은 자동 보정하지 않고 검토 대상으로 남깁니다. 표에서 직접 수정한 금액에도 같은 기준을 적용합니다.
- 은행명은 지원하는 은행명·약칭과 일치해야 합니다. `KB`, `NH` 등의 약칭은 정식 은행명으로 정리합니다.
- 필수 항목에 오류가 남으면 다운로드를 차단합니다.
- 다운로드 파일명은 추가 입력 없이 차량번호·총액·생성 시각(한국 시간)으로 작성합니다. 예: `123가4567_35,000원_1031_142035.xlsx`, `123가4567외2대_총850,000원_1031_142035.xlsx`. 차량번호가 없으면 `송금3건_총850,000원_1031_142035.xlsx`처럼 표시합니다. 차량 수는 중복을 제외하며, 건수는 분할 후 실제 이체 행 수입니다. 같은 초의 재다운로드에는 `_2`, `_3` 순번을 붙입니다.
- 다운로드를 요청해도 입력과 이체 내역은 자동 삭제하지 않습니다. 브라우저 저장 여부를 확인한 후 **전체 초기화**를 눌러 주세요. 현재 페이지를 열어 둔 동안 **되돌리기**와 **마지막 다운로드 내역 복원**도 사용할 수 있습니다.
- 코멘트 금액은 만원 단위로 딱 떨어지면 1,000,000원 → 100만원처럼 표시하고, 나머지가 있으면 35,000원 → 35,000원, 1,005,000원 → 1,005,000원처럼 원 단위 전체 금액으로 표시합니다. 이체파일과 파일명의 금액은 기존 표기를 유지합니다.
- 스레드별 송금완료 코멘트를 생성하고 클릭하여 복사할 수 있습니다. 같은 스레드에 여러 이체 행이 있으면 코멘트 끝에 총액을 함께 표시합니다(예: 총액 300만원). 자동 분할 건도 중복 합산 없이 총액에 반영합니다. 코멘트를 복사하려면 실제 은행 송금 완료와 수취인·금액 확인 질문에 동의해야 합니다. 이 질문은 은행 연동 조회가 아니므로 은행 화면에서 확인한 뒤 사용합니다.

### Excel 출력 열

| 열 | 항목 |
| --- | --- |
| A | 입금은행 |
| B | 입금계좌번호 |
| C | 입금액(원) |
| D | 출금통장표시 |
| E | 입금통장표시 |
| F | CMS코드 |

예금주 정보는 추출하거나 저장하지 않습니다. 코멘트용 계좌 구분명은 은행 이체파일에 포함하지 않습니다. 은행 업로드 전 원문과 대조하고, 실제 계좌와 수취인 일치 여부는 은행에서 확인합니다.

## 데이터 보관

- 입력 내용과 첨부 파일은 서버로 전송하지 않고 브라우저에서 처리합니다.
- 탁송체크의 수동확인 금액·사유·확인 시각은 현재 브라우저의 로컬 저장소에 최대 500건 보관합니다. 화면의 **저장된 수동확인 전체 삭제**로 지울 수 있습니다.
- 탁송체크의 처리 완료 표시는 현재 페이지에서만 유지되며 전체 초기화 시 지워집니다.
- 이체 도구의 되돌리기·다운로드 복원 정보는 현재 페이지를 열어 둔 동안만 유지됩니다.
- 다운로드한 파일은 사용자 기기에 남습니다.

```text
WorkTool/
```

HTML·CSS·JavaScript로 구성된 정적 웹 프로젝트입니다. 탁송체크를 수정할 때는 기본 화면인 `dispatch-tool.html`과 이를 확장하는 `dispatch.html`을 함께 확인합니다.

## 회귀 테스트

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다. 금액 추출·직접 수정, 은행명 검증, 분할 한도와 중복 검사를 확인합니다.

```bash
node --test tests/*.test.cjs
```

GitHub Actions에서 `main` 브랜치 변경과 Pull Request마다 동일한 회귀 테스트를 자동 실행합니다.

탁송체크는 같은 차량번호가 여러 번 입력되어도 업체 기록의 정렬·중복 판정을 조회 실행당 한 번만 수행합니다. 동일 탁송 기록의 불필요한 공백·전각문자 차이는 중복으로 묶되, 금액·운행일시·메모 내용 등이 실제로 다르면 기존처럼 별도 건으로 검토합니다. 하나은행 이체툴은 은행 약칭과 계좌번호의 하이픈·공백 표기 차이가 있어도 같은 은행·계좌·금액·차량번호인 이체 건을 중복으로 판정하며, 자동 분할 건은 기존처럼 예외로 처리합니다.

### Excel XML 안전성

하나은행 이체파일을 만들 때 은행명·계좌번호·통장표시·CMS코드 등 문자 셀의 XML 금지 제어문자를 제거하고, 허용된 탭·줄바꿈과 앞뒤 공백은 보존합니다. 원문의 제어문자를 제외한 내용은 그대로 유지하며, 특수문자(`&`, `<` 등)는 XML에 안전하게 기록합니다. 이체를 실행하기 전 은행 업로드 화면의 수취인·금액을 반드시 확인하세요.
