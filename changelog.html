2026-11-04

탁송체크

  • 탁송비용, 탁송비용 부가세, 총 탁송비용 항목을 추가했습니다. 부가세는 탁송비용의 10%, 총 탁송비용은 비용과 부가세의 합계입니다.
  • 비용·부가세·총액을 각각 클릭하면 쉼표와 원 표시를 제외한 숫자를 복사합니다. 미입력·선택 필요 상태는 복사하지 않습니다.
  • 세 비용 항목을 TXT·Excel·PDF 저장과 체험 데이터에 반영했습니다. 빈칸은 미입력으로 유지하며, 탁송건을 선택하면 해당 기록의 비용을 적용합니다.
  • 동일 차량의 여러 탁송 기록을 날짜·업체·상태·금액·출발지·원본 위치로 비교하고 표시할 한 건을 직접 선택할 수 있습니다. 선택은 결과·복사·저장에 반영되며 자동 조회로 되돌릴 수 있습니다.
  • 상단에 중복 검토 필요 차량 수와 검토 목록 링크를 추가했습니다. 링크는 기존 필터를 해제하고 검토 대상만 표시하며, 탁송건을 적용한 차량은 목록에서 빠집니다.
  • 원본 탁송일시에 시간까지 표시하고, 같은 날이라도 시간이 다른 기록을 구분합니다. 날짜 매칭과 기간 필터는 일자 기준으로 유지합니다.
  • 탁송완료일시·탁송접수일시를 함께 표시하고 두 값 중 최신 시각으로 기록을 정렬합니다. 둘 다 없으면 탁송일시를 사용합니다. 입력 날짜가 있으면 같은 운행일 내에서 비교하며, 금액 충돌·별도 운행은 사용자가 최종 선택합니다.
  • 체험 자료에도 업체별 접수 시각 열과 완료일시를 넣었습니다. 12서7567·25마7579는 중복 검토·기록 선택, 77다1234는 캐리어 분류 예시입니다.

공통

2026-11-03

탁송체크

  • 차량 선택 체크박스를 누른 채 드래그하여 여러 행을 연속 선택·해제할 수 있습니다.
  • 한빛탁송·오픈마일·렌톡별 일괄 선택 체크박스를 추가했습니다. 현재 필터에 맞는 차량에 적용하고 선택 대수와 부분 선택 상태를 표시합니다.

  • 상세 사용방법 페이지를 만들고 홈·도구 화면에 새 탭 링크를 추가했습니다.

하나은행 이체툴

  • 상세 사용방법 페이지를 만들고 입력·검증·금액 분할·통장 메모·다운로드·복원·코멘트 사용을 안내합니다.
  • 송금완료 코멘트의 금액이 만원 단위로 나누어떨어지면 1,000,000원 → 100만원으로 표시합니다. 나머지가 있으면 35,000원 → 35,000원처럼 원 단위 전체 금액으로 표시합니다.
  • 딜러 송금 코멘트에서 금액 대신 차대금을 사용합니다. 예: 차대금 100만원 딜러에게 송금완료.
  • 분할·복수 송금 코멘트에 총액을 함께 표시합니다. 자동 분할한 건은 원래 지급 건으로 묶어 중복 합산하지 않습니다.

탁송체크
