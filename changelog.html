2026-11-26

조회 결과 페이지 나누기

  • 탁송체크: 조회 결과를 한 페이지에 30건씩 보여 줘요. 표 아래 페이지 번호·‹ › 단추로 넘기고, 페이지당 드롭다운에서 10·30·50·100건을 고를 수 있어요(이 기기에 기억). 중첩 일정·비용 드롭다운도 표에 맞게 작게 줄였어요. 필터·검색·정렬을 바꾸면 1페이지로 돌아가요. 복사·저장·캡처와 전체 선택은 다른 페이지 결과도 함께 포함해요.

2026-11-25

실수 방지 보강 · Windows 포터블

  • 탁송체크: 업체 엑셀의 탁송일정·탁송비용·렌톡 캐리어 구분 열 값이 절반 넘게 평소 형식과 다르면 업체 양식이 바뀌었을 수 있다고 알려 줘요. 파일 목록에도 '⚠ 양식 확인 필요'가 붙어요.
  • 탁송체크: '복사함·완료' 표시를 오늘 하루 동안 이 기기에 남겨요. 실수로 새로고침하거나 다시 조회해도 이어서 볼 수 있어요. 전체 초기화를 누르면 지워져요.
  • 이체파일: 오늘 이미 받은 이체파일과 은행·계좌·금액이 같은 건이 있으면 다운로드 전에 한 번 더 물어봐요. 계좌번호 원문은 남기지 않아요.
  • 슬랙봇 회신 금액을 10원 단위로 반올림해요.
  • Windows 앱: 같은 기능을 넣고, 압축만 풀면 바로 실행되는 포터블 ZIP(WorkTool.exe)을 만들었어요. 설정·표시는 ZIP 옆 Data 폴더에 남아요.

2026-11-18

그림 사용법 체험 화면 · 다크 모드

  • 그림 사용법에 직접 눌러 보는 체험 화면을 넣었어요. 탁송체크는 차량목록 붙여넣기 → 파일 첨부 → 조회 → 걸러 보기·일정 고르기·복사까지, 이체파일은 붙여넣기 → 추출 → 오류 고치기·통장 메모 → 검토 확인 → 다운로드·송금 코멘트까지 실제처럼 따라 해 볼 수 있어요. 위쪽 ‘지금 할 일’이 다음에 누를 곳을 알려 줘요.
  • 체험 화면은 가상 데이터만 쓰고 파일을 만들거나 저장하지 않아요. 실제 화면 스크린샷은 체험 화면 아래 링크로 볼 수 있어요.
  • 다크 모드에서 사용법 페이지(그림 사용법·탁송체크·이체 상세 사용방법) 글자가 흰 바탕에 묻혀 안 보이던 문제를 고쳤어요. 라이트 모드의 그림 사용법 위쪽 메뉴 글자도 진하게 했어요.
  • 쓰지 않던 사용 설명서(guide.html)를 지웠어요. 예전 주소로 들어오면 그림 사용법으로 옮겨 가요. 홈 메뉴의 '사용 설명서'도 '그림 사용법'으로 바꿨어요.

가독성 개선

  • 탁송체크 글자를 읽기 쉽게 다듬었어요. 탭·필터·카드 이름·표 머리글·파일 정보처럼 10~12px이던 보조 글자를 13px 안팎으로 키웠어요.
  • 흐리던 회색 글자와 상태 배지(비용 확인·슬랙봇 문의·미조회 등)를 진하게 해서, 라이트·다크 모드 모두 웹 접근성 대비 기준(4.5:1)을 넘게 했어요.
  • 첨부 파일 목록이 3개까지 한눈에 보이고, '주유비용/충전비용 (원)'·'부가세 10%' 머리글이 잘리지 않게 열 너비를 넓혔어요.

진행 중 표시

  • 탁송체크 위쪽 카드와 탭의 '미조회'를 '진행 중'으로 바꿨어요. 진행 중은 기록은 있지만 아직 탁송완료 전인, 탁송 중·배정완료 차량이에요(취소는 제외). 표·캡처·저장 파일의 상태도 '진행 중'으로 보여요. 미조회 차량은 '확인 필요' 탭에서 볼 수 있어요.

표 글자 굵기 · 눌러서 복사

  • 탁송체크 표의 '금액 (원)' 항목 이름을 '주유비용/충전비용 (원)'으로 바꿨어요. 캡처 이미지, TXT·엑셀·PDF 저장 파일, 사용법 문서의 이름도 같이 바꿨어요.
  • 탁송체크 표에서 과하게 굵던 글자를 정리했어요. 값은 보통 굵기로, 차량번호와 주유금액만 살짝 강조해요.
  • 눌러서 복사되는 값에 점선 밑줄과 '복사' 표시를 붙이고, 표 위에 안내 문구를 넣었어요. 차량번호·주유금액에 더해 탁송일정·탁송비용·부가세도 눌러서 복사할 수 있어요. 숫자는 쉼표 없이 복사돼요.
  • 주유금액을 쉼표가 있는 숫자(12,350)로 보여 줘요.
  • 다크 모드에서 한 줄 걸러 밝은 회색 배경이 나와 글자가 잘 안 보이던 문제를 고쳤어요.

결과 캡처 · 체험·예시 데이터 제거

  • 탁송체크에 결과 캡처를 넣었어요. 결과 내보내기 줄의 캡처 복사는 조회 결과를 표 이미지로 클립보드에 복사하고(Slack에 바로 붙여넣기), 캡처 저장은 PNG 파일로 저장해요. 저장 범위와 체크한 줄을 따르고, 합계가 함께 들어가요.
  • 쓰지 않는 탁송체크 '체험 데이터'와 이체파일 '예시로 연습하기'를 지웠어요.
  • 한글이 숫자 문자 참조(&#52264; 같은 형식)로 저장된 엑셀도 탁송체크가 읽을 수 있게 했어요.
  • 사용법 그림은 가상 업체 엑셀·가상 이체 요청으로 다시 찍었어요.

불필요한 항목 정리

  • 이체파일 1단계 오른쪽 '입력 예시' 상자를 지웠어요. '예시로 연습하기' 버튼은 입력칸 아래 버튼 줄로 옮겼고, 누르면 예시가 입력칸에 바로 들어가요. 입력칸이 화면 너비를 다 쓰고, 휴대폰에서는 1단계가 한 화면에 들어와요.
  • 탁송체크: 제목 위아래의 영문 표시·설명 문장, '이 기기에서만 처리' 표시, 카드 안 안내 문장, '자동인식' 표시, 조회 버튼 아래 안내, 빈 화면 태그, 아래쪽 열 안내 줄을 지웠어요.
  • 탁송체크 표: '선택'과 '완료' 체크를 나란히 놓아 한 줄 높이를 줄이고, 전체 선택·필터 지우기·열 너비 초기화를 '조회 결과' 제목 줄로 올렸어요.
  • 이체파일: 단계 버튼의 보조 설명, 1단계 도움말 상자(사용 안내 창과 중복), 2단계의 반복 안내, 3단계 열 순서 설명을 지우고 남은 안내 문장은 짧게 줄였어요.
  • 홈: 긴 설명 문장을 줄이고 아래쪽 버전 표시를 지웠어요.
  • 바뀐 화면에 맞춰 사용법 그림을 다시 만들었어요.

화면 배치

  • 탁송체크 위쪽 머리줄 세 겹을 하나로 합쳤어요. 체험 데이터·전체 초기화·도움말(?) 버튼이 제목 옆에 모였어요.
  • 탁송체크 입력 카드 두 개를 나란히 넓게 놓고, 차량 조회하기 버튼을 그 아래 오른쪽에 뒀어요. 결과 필터는 탭 한 줄, 필터·검색 한 줄로 정리했어요.
  • 이체파일 1단계 버튼을 한 줄로 모았어요(입력칸 추가·전체 초기화 왼쪽, 이체정보 추출하기 오른쪽).
  • 이체파일 2단계는 이체 내역 표를 넓은 왼쪽에, 통장 메모·CMS 설정을 오른쪽에 두고, 표 도구 버튼을 한 줄로 합쳤어요.
  • 이체파일 3단계는 미리보기 → 확인 체크 → 다운로드 → 주의 → 송금 코멘트 순서로 바꿨어요.
  • 휴대폰에서 이체 내역 카드가 상자 밖으로 넘치던 문제와 3단계 화면이 옆으로 밀리던 문제를 고쳤어요.
  • 바뀐 배치에 맞춰 사용법 그림을 다시 만들었어요.

2026-11-17

사용법 그림

  • 그림 사용법 스크린샷 4장을 지금 Liquid Glass 화면으로 다시 찍었어요. 화면 위에는 번호와 파란 테두리만 표시하고, 설명은 아래 카드에 해요체로 정리했어요.
  • 그림 사용법·상세 사용방법의 그림 설명을 새 그림의 번호에 맞춰 다시 썼어요.
  • 탁송체크 표에서 '중첩 비용 · 선택 필요' 드롭다운과 탁송비용 머리글이 잘리지 않게 기본 열 너비를 넓혔어요.
  • 연결된 곳이 없던 예전 탁송체크 화면(dispatch-tool.html)을 지웠어요.

문구·사용법

  • 탁송체크 상세 사용방법·README를 지금 화면에 맞게 줄였어요. 지금은 없는 수동확인, 중복 검토 목록, 탁송건 선택, 처리 완료 일괄 표시 설명을 지우고, 실제 조회 기준·조회 상태·일정/비용 선택·필터·저장 범위를 정리했어요.
  • 사용법 문서가 없는 기능을 다시 설명하거나 딱딱한 말투가 섞이면 자동 테스트가 알려 줘요.
  • 사이트 전체 안내 문구를 친근한 해요체(예: 확인해요, 붙여요)로 바꿨어요.
  • 이체파일 상세 사용방법과 README를 지금 화면에 맞게 다시 썼어요. 예전 3페이지 구성·4시간 임시 저장·되돌리기처럼 지금은 없는 기능 설명을 지웠어요.
  • 사용 설명서의 '입력 내용이 사라졌어요' 등 자주 묻는 질문을 실제 동작에 맞게 고쳤어요.
  • 한글이 줄 끝에서 단어 중간에 끊기지 않게 했고, 사용법 페이지 위쪽 메뉴도 유리 스타일로 맞췄어요.

화면·공통

  • Liquid Glass 화면을 다듬었어요. 유리 효과는 바깥 판에만 쓰고 안쪽 상자는 겹쳐 흐리지 않게 해 글자가 더 또렷해요.
  • 바깥 판·안쪽 상자·버튼의 모서리 둥글기를 단계별로 맞추고, 흰 바탕에 묻히던 버튼에 얇은 테두리를 넣었어요. 버튼은 캡슐 모양으로 통일했어요.
  • 남아 있던 녹색 아이콘, 표 아래 흰 빈칸, 탁송체크 검색칸 이중 테두리, 다크 모드의 흰 ? 버튼을 정리했어요.
  • 휴대폰에서 위쪽 메뉴가 두 줄로 깨지지 않고, 이체 단계 버튼 글자가 한 글자씩 줄바꿈되지 않게 했어요.
  • 두 도구 위쪽 메뉴와 홈에 '그림 사용법' 링크를 넣었어요.
  • 이체 금액에서 3.5억(→5억), 35,000.50원(→50원), -35,000원(→35,000원), 1/2만원(→2만원)처럼 잘못 읽히던 표기를 금액 확인 오류로 표시해요.
  • 자동 테스트를 지금 화면 기준으로 다시 작성하고, 이체파일 실제 브라우저 테스트를 추가했어요.

하나은행 이체파일

  • 이미 추출한 스레드를 고쳐서 다시 추출하면 전에 넣은 건은 다시 넣지 않고 새 건만 추가해요. 같은 스레드를 다른 입력칸에 또 붙여넣으면 건너뛰어요.
  • 같은 은행·계좌·금액이 두 줄 이상이면 '두 번 송금 주의' 검토로 표시하고, 휴대폰 번호 형태의 계좌번호도 원문 확인 검토로 표시해요.
  • 날짜·시간 줄을 계좌번호로 잘못 읽지 않아요.
  • 나누면 100건을 넘는 큰 금액은 화면이 멈추지 않도록 나누지 않고 오류로 표시해요.
  • 메모에 섞인 보이지 않는 제어문자를 지워 엑셀 파일이 깨지지 않게 했어요.
  • 검토 확인 체크 후 내역을 바꾸면 다시 확인해야 받을 수 있고, 다운로드 버튼을 연달아 눌러도 한 번만 저장돼요.
  • 붙여넣기 한도를 5만 자로 늘리고 잘리면 안내해요. 받지 않은 내역이 있을 때 새로고침·창 닫기를 하면 한 번 물어요.

2026-11-04

탁송체크

  • 탁송비용, 탁송비용 부가세, 총 탁송비용 항목을 추가했어요. 부가세는 탁송비용의 10%, 총 탁송비용은 비용과 부가세의 합계예요.
  • 비용·부가세·총액을 각각 클릭하면 쉼표와 원 표시를 제외한 숫자를 복사해요. 미입력·선택 필요 상태는 복사하지 않아요.
  • 세 비용 항목을 TXT·Excel·PDF 저장과 체험 데이터에 반영했어요. 빈칸은 미입력으로 유지하며, 탁송건을 선택하면 해당 기록의 비용을 적용해요.
  • 동일 차량의 여러 탁송 기록을 날짜·업체·상태·금액·출발지·원본 위치로 비교하고 표시할 한 건을 직접 선택할 수 있어요. 선택은 결과·복사·저장에 반영되며 자동 조회로 되돌릴 수 있어요.
