2026-11-17

사용법 그림

  • 그림 사용법 스크린샷 4장을 지금 Liquid Glass 화면으로 다시 찍었어요. 화면 위에는 번호와 파란 테두리만 표시하고, 설명은 아래 카드에 해요체로 정리했어요.
  • 그림 사용법·상세 사용방법의 그림 설명을 새 그림의 번호에 맞춰 다시 썼어요.
  • 탁송체크 표에서 '중첩 비용 · 선택 필요' 드롭다운과 탁송비용 머리글이 잘리지 않게 기본 열 너비를 넓혔어요.
  • 연결된 곳이 없던 예전 탁송체크 화면(dispatch-tool.html)을 지웠어요.

문구·사용법

  • 탁송체크 상세 사용방법·README를 지금 화면에 맞게 줄였어요. 지금은 없는 수동확인, 중복 검토 목록, 탁송건 선택, 처리 완료 일괄 표시 설명을 지우고, 실제 조회 기준·조회 상태·일정/비용 선택·필터·저장 범위를 정리했어요.
  • 사용법 문서가 없는 기능을 다시 설명하거나 딱딱한 말투가 섞이면 자동 테스트가 알려 줘요.
  • 사이트 전체 안내 문구를 친근한 해요체(예: 확인해요, 붙여요)로 바꿨어요.
  • 이체파일 상세 사용방법과 README를 지금 화면에 맞게 다시 썼어요. 예전 3페이지 구성·4시간 임시 저장·되돌리기처럼 지금은 없는 기능 설명을 지웠어요.
  • 사용 설명서의 '입력 내용이 사라졌어요' 등 자주 묻는 질문을 실제 동작에 맞게 고쳤어요.
  • 한글이 줄 끝에서 단어 중간에 끊기지 않게 했고, 사용법 페이지 위쪽 메뉴도 유리 스타일로 맞췄어요.

화면·공통

  • Liquid Glass 화면을 다듬었어요. 유리 효과는 바깥 판에만 쓰고 안쪽 상자는 겹쳐 흐리지 않게 해 글자가 더 또렷해요.
  • 바깥 판·안쪽 상자·버튼의 모서리 둥글기를 단계별로 맞추고, 흰 바탕에 묻히던 버튼에 얇은 테두리를 넣었어요. 버튼은 캡슐 모양으로 통일했어요.
  • 남아 있던 녹색 아이콘, 표 아래 흰 빈칸, 탁송체크 검색칸 이중 테두리, 다크 모드의 흰 ? 버튼을 정리했어요.
  • 휴대폰에서 위쪽 메뉴가 두 줄로 깨지지 않고, 이체 단계 버튼 글자가 한 글자씩 줄바꿈되지 않게 했어요.
  • 두 도구 위쪽 메뉴와 홈에 '그림 사용법' 링크를 넣었어요.
  • 이체 금액에서 3.5억(→5억), 35,000.50원(→50원), -35,000원(→35,000원), 1/2만원(→2만원)처럼 잘못 읽히던 표기를 금액 확인 오류로 표시해요.
  • 자동 테스트를 지금 화면 기준으로 다시 작성하고, 이체파일 실제 브라우저 테스트를 추가했어요.

하나은행 이체파일

  • 이미 추출한 스레드를 고쳐서 다시 추출하면 전에 넣은 건은 다시 넣지 않고 새 건만 추가해요. 같은 스레드를 다른 입력칸에 또 붙여넣으면 건너뛰어요.
  • 같은 은행·계좌·금액이 두 줄 이상이면 '두 번 송금 주의' 검토로 표시하고, 휴대폰 번호 형태의 계좌번호도 원문 확인 검토로 표시해요.
  • 날짜·시간 줄을 계좌번호로 잘못 읽지 않아요.
  • 나누면 100건을 넘는 큰 금액은 화면이 멈추지 않도록 나누지 않고 오류로 표시해요.
  • 메모에 섞인 보이지 않는 제어문자를 지워 엑셀 파일이 깨지지 않게 했어요.
  • 검토 확인 체크 후 내역을 바꾸면 다시 확인해야 받을 수 있고, 다운로드 버튼을 연달아 눌러도 한 번만 저장돼요.
  • 붙여넣기 한도를 5만 자로 늘리고 잘리면 안내해요. 받지 않은 내역이 있을 때 새로고침·창 닫기를 하면 한 번 물어요.

2026-11-04

탁송체크

  • 탁송비용, 탁송비용 부가세, 총 탁송비용 항목을 추가했어요. 부가세는 탁송비용의 10%, 총 탁송비용은 비용과 부가세의 합계예요.
  • 비용·부가세·총액을 각각 클릭하면 쉼표와 원 표시를 제외한 숫자를 복사해요. 미입력·선택 필요 상태는 복사하지 않아요.
  • 세 비용 항목을 TXT·Excel·PDF 저장과 체험 데이터에 반영했어요. 빈칸은 미입력으로 유지하며, 탁송건을 선택하면 해당 기록의 비용을 적용해요.
  • 동일 차량의 여러 탁송 기록을 날짜·업체·상태·금액·출발지·원본 위치로 비교하고 표시할 한 건을 직접 선택할 수 있어요. 선택은 결과·복사·저장에 반영되며 자동 조회로 되돌릴 수 있어요.
  • 상단에 중복 검토 필요 차량 수와 검토 목록 링크를 추가했어요. 링크는 기존 필터를 해제하고 검토 대상만 표시하며, 탁송건을 적용한 차량은 목록에서 빠져요.
  • 원본 탁송일시에 시간까지 표시하고, 같은 날이라도 시간이 다른 기록을 구분해요. 날짜 매칭과 기간 필터는 일자 기준으로 유지해요.
  • 탁송완료일시·탁송접수일시를 함께 표시하고 두 값 중 최신 시각으로 기록을 정렬해요. 둘 다 없으면 탁송일시를 사용해요. 입력 날짜가 있으면 같은 운행일 내에서 비교하며, 금액 충돌·별도 운행은 사용자가 최종 선택해요.
  • 체험 자료에도 업체별 접수 시각 열과 완료일시를 넣었어요. 12서7567·25마7579는 중복 검토·기록 선택, 77다1234는 캐리어 분류 예시예요.

하나은행 이체툴

  • 상세 사용방법 페이지를 만들고 입력·검증·금액 분할·통장 메모·다운로드·복원·코멘트 사용을 안내해요.
  • 송금완료 코멘트의 금액이 만원 단위로 나누어떨어지면 1,000,000원 → 100만원으로 표시해요. 나머지가 있으면 35,000원 → 35,000원처럼 원 단위 전체 금액으로 표시해요.
  • 딜러 송금 코멘트에서 금액 대신 차대금을 사용해요. 예: 차대금 100만원 딜러에게 송금완료.
  • 분할·복수 송금 코멘트에 총액을 함께 표시해요. 자동 분할한 건은 원래 지급 건으로 묶어 중복 합산하지 않아요.
